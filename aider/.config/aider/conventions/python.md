Please follow the following conventions only when writing Python code:

Embrace Python's readability by following PEP 8 conventions with consistent 4-space indentation and reasonable line lengths. Make your code explicit through type hints, descriptive variable names, and clear docstrings that document parameters, return types, and exceptions. Leverage Python's distinctive strengths by using f-strings for formatting, list/dict comprehensions for data transformation, and context managers with `with` statements for resource handling. Structure your code to follow Python's "explicit is better than implicit" philosophy, preferring clear intent over clever shortcuts. Take advantage of Python's built-in data structures and operations like slicing, unpacking, and iteration tools such as generators for memory efficiency. When writing functions, keep them focused with single responsibilities, use keyword arguments for clarity, and return early to avoid excessive nesting.
